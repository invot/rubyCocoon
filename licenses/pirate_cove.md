# Cocoon Cove proposal assets

The user supplied the original GLB downloads. Their embedded glTF `asset.extras`
metadata identifies the creator, source and CC BY 4.0 licence below.

- **Towns**, by **loafbrr**: https://sketchfab.com/3d-models/towns-eab6312a2693464ea7fdea00d69737b3
- **WholeHouseFBX**, by **loafbrr**: https://sketchfab.com/3d-models/wholehousefbx-874ea6b515d945b185f659103830f438
- Creator: https://sketchfab.com/loafbrr
- Licence: Creative Commons Attribution 4.0 International,
  https://creativecommons.org/licenses/by/4.0/

Derived meshes in `assets/exteriors/cove_*.res` are extracted, centered, grounded,
given mesh LODs where appropriate, and their textures resized and smoothed through
the existing scenery pipeline. The nine buildings have closed, opaque exteriors;
WholeHouseFBX also receives simpler matching materials. No ships or rafts are extracted.

The separate user-supplied **Pirate Town Pack.zip** contains five OBJ files and six
textures, but no referenced MTL files or licence statement. Its source files stay
unchanged in Downloads; it is inspected as reference, not included in the game assets.
The **Hidden Cove** image is a composition reference only and is not redistributed.
