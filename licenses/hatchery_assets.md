# User-supplied hatchery model packs

Provided by the project owner on 2026-11-08 for use in the egg-hatching cinematic:

| Archive | Game use | Attribution recorded in archive |
| --- | --- | --- |
| `Sci-Fi Platforms.zip` | Lower platform | No author, source page or licence file included |
| `War Doctor's TARDIS Interior (Old).zip` | Merge cinematic's chamber walls and floor | No author, source page or licence file included |
| `TCM Core (Virlance).zip` | Overhead core and three tongs | “Virlance” appears in the supplied archive title; no explicit authorship or licence file included |

The archives contain OBJ geometry and PNG textures, without the MTL files referenced by the OBJs. The original
downloads are unchanged. Extracted sources stay in the ignored `psx/hatchery/` directory. Simplified, textured,
smoothed game resources are stored under `assets/interiors/hatch_*`.

Modifications: coordinate conversion, centring, scaling, mesh simplification, material reconstruction, recolouring
(bronze core, stone and brass platform), texture smoothing, articulated tongs and cinematic lighting.

The hatch's chamber is not built from a supplied pack: `assets/interiors/hatch_room.res` and `hatch_conduit.res` are
generated by `tools/hatchery_chamber.gd`. The merge cinematic's chamber, `assets/interiors/hatch_roundels.res`, keeps
only the walls and ceiling of `War Doctor's TARDIS Interior (Old).zip`, and the positions of its windows. Its floor, glass,
console, rotor, struts, cables and doorway are left out; the flagstones, plaster and bottle-bottom glass are the game's own. The copy of that archive supplied on 2026-11-08 was empty (22 bytes), so the
bake uses the sources extracted earlier to `psx/hatchery/room/`. The model depicts a set from a television series, so
check its rights before any public release.

No licence grant is inferred from the filenames. The packs' original source URLs, creators and redistribution
terms remain to be recorded before public distribution. This provenance note is not a replacement licence.
