# Ruby Cocoon project instructions

Read and follow the shared project rules in `AGENTS.md` before editing this game.
That file is the canonical source for both Claude and Codex; update it when changing project rules.
Before spawning a subagent, or running tests and other minor tasks yourself, offload the work to the local model at `http://localhost:1235/v1` as described in `AGENTS.md` under "Offloading to the local model"; if it isn't reachable, proceed without it.
