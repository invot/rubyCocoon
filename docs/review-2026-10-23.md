# Bug fixes and playthrough inspection — October 23, 2026

## Changes

- Save JSON is written and flushed to a sibling temporary file, with write errors checked before replacing the slot. Failed writes leave the original slot untouched. Successful replacement was tested on Windows.
- Field obstacles accept either element of a healthy dual-element beast. The matching element also controls the displayed move, sound, and flash.
- Incense modifies the effective wild spawn target instead of overwriting the map's base target. Expiration restores normal spawning, and activating incense on the current map affects subsequent spawn checks.
- Each music player cancels its previous fade tween before reuse, preventing an earlier fade's stop callback from stopping a newly selected track.
- Terrain hole shader uniforms update on the initial frame and when player position changes. Building a map invalidates the cached position. This avoids redundant idle uniform writes; no GPU speedup was measured.
- The map tour exposed shallow house steps whose rectangle became negative after a fixed inset. The inset now respects the rectangle's dimensions.
- Added `tools/check_review_fixes.gd` and registered it in the full test runner.

## Validation

All 13 new regression assertions pass: both-element obstacle eligibility, fainted-beast rejection, first and replacement saves, loading the replacement, temporary-file cleanup, calm/lure activation and expiration, shader initialization/movement, and rapid music changes. Regression saves are confined to `build/review_saves/`.

Final script check: 117 scripts, zero broken. Final ring-editor touch check: zero problems. `git diff --check` passed.

The first suite runner printed all passing results but then exited with a shell parse error because its file was edited while it was running. A fresh runner invocation for the changed map tour and new regression scenario exited successfully.
